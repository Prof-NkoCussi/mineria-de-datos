# Datos

## Bank Marketing (proyecto 01)

El notebook `proyectos/01_parcial_bank_marketing_regresion_logistica.ipynb` usa el dataset **Bank Marketing** del repositorio UCI Machine Learning:

- Fuente: https://archive.ics.uci.edu/dataset/222/bank+marketing
- Archivo utilizado: `bank-additional-full.csv` (41.188 registros, 20 variables y el objetivo `y`; separador `;`)
- Referencia: S. Moro, P. Cortez y P. Rita. *A Data-Driven Approach to Predict the Success of Bank Telemarketing.* Decision Support Systems, 2014.

Para ejecutarlo, descargar el archivo y guardarlo en esta carpeta como `data/bank-additional-full.csv`.
Los archivos `.csv` están excluidos del repositorio (ver `.gitignore`).
